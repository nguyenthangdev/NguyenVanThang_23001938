# Bài thực hành số 6 - VueJS

Ba bài tập gộp trong một dự án Vite + Vue 3, chuyển bài bằng thanh tab.

| Bài | Component | Nội dung |
| --- | --- | --- |
| 1 | `src/components/Bai1.vue` | Thẻ thông tin sinh viên |
| 2 | `src/components/Bai2.vue` | Đặt vé xem phim |
| 3 | `src/components/Bai3.vue` | Quản lý công việc cá nhân |

## Chạy dự án

```
npm install
npm run dev
```

Mở địa chỉ Vite in ra (thường là http://localhost:5173).
